# Hosting SDK repository

> **Not Yet Implemented.** Intended development areas are plans, not available features.

[Hosting SDK on GitHub](https://github.com/Rustic-Game-Engine/hosting-sdk).

## Current contents and development language

As checked in the available checkout on 12 October 2026, this repository contains only `LICENSE` (Apache 2.0). **Implementation has not begun.** No SDK, API specification, package format, language, endpoints or supported runtime matrix has been established by source.

Its planned purpose is software integrating game-server deployment, scaling, monitoring and infrastructure management. Those are intended development areas, not available cloud operations. This public repository is separate from the native engine and the private managed cloud platform.

## Prerequisites

Git is enough to inspect the repository. No SDK-specific installation, credential setup or build prerequisites exist yet. Building the engine does not install a hosting SDK.

## Start your own version
