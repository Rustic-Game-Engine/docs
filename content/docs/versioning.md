# Documentation versioning

The header **Docs v0.1** identifies this website, not the engine. Engine release tags, scripting API 1.0/1.1 and project/scene schema versions have independent meanings. Use [Versions and changes](/docs/reference/versions) when writing compatibility notes.

There is one maintained website version. Do not invent an engine release from the docs package version or add empty archives. When multiple versions are actually maintained, scope navigation/search to the selected version, preserve deep links and document migration. Today, state the engine source revision reviewed and the API/platform restrictions on affected pages.
